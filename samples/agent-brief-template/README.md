# Agent Brief Template

A static HTML template for general-agent research and decision outputs. It is
intended for strategy briefs, vendor comparisons, technical recommendations,
decision memos, and executive summaries.

## Use Cases

- Present a recommendation with confidence and residual risk.
- Compare options with a clear decision frame.
- Separate facts, inference, gaps, and actions.
- Produce a clean mobile-readable and print-friendly artifact.

## Run

Open `index.html` directly in a browser, or serve the repository root:

```bash
python3 -m http.server 4173
```

Then visit:

```text
http://127.0.0.1:4173/samples/agent-brief-template/index.html
```
