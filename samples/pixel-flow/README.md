# Pixel Flow

A pixel-art Flow puzzle (also known as numberlink). Connect every pair of
coloured dots with a pipe — without crossing — and cover the whole grid. A
fresh path-drawing puzzle genre alongside the other `samples/` pixel games.

## Features

- 32-level campaign on growing grids (5×5 → 14×14).
- Every puzzle is generated by carving the grid into simple paths, so a
  full-coverage solution is always guaranteed to exist; seeded so each level
  is the same puzzle every time.
- True Flow rules — drag a pipe from a dot, retrace to undo, and crossing
  another colour's pipe cuts it (just like the original).
- 3-star rating by board coverage — connect every pair for the clear, fill
  100% of the grid for a perfect flow.
- Drag-to-draw input that works the same with a mouse or a finger.
- Level select with progressive unlocks and per-level star records, saved to
  `localStorage`.
- Up to 10 distinct pipe colours, rounded ribbon rendering.
- English / 中文 toggle.
- Responsive 360:480 board — scales on desktop, fills the screen on mobile.

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4230
```

Then visit `http://127.0.0.1:4230/index.html`.

## Play

- Drag from any coloured dot toward its matching dot to lay a pipe.
- Pipes can't cross — drawing into another colour's pipe cuts it short.
- Drag back along your own pipe to retract it.
- Connect every pair to win; cover all 100% of the grid for 3 stars.

## Structure

- `index.html` - shell, title / level-select / game screens, win overlay.
- `css/style.css` - responsive 360:480 shell, HUD, level grid.
- `js/data.js` - level seeds and solvable-puzzle generation.
- `js/i18n.js` - English / Chinese strings.
- `js/art.js` - backdrop, grid, pipe ribbons, endpoint dots.
- `js/game.js` - pipe-drawing logic, cutting, win detection, save.
