# Pixel Merge Garden

A polished merge-idle garden sample for casual progression loops, with orders, crop mutations, rain boosts, greenhouse scaling, passive income, merge streaks, and mobile-friendly grid controls.

## Loop

Buy seeds, merge matching crop levels, fulfill orders, trigger water boosts, discover silver and gold mutations, unlock stronger greenhouse scaling, and collect passive coin income.

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4179
```
