# Three Lowpoly Island

A full-screen Three.js procedural low-poly island scene with buildings, trees, moving boats, shadows, fog, and custom pointer camera controls. It imports the vendored module from `../../../shared/`.

## Run

Serve the folder so browser module imports can load correctly:

```bash
python3 -m http.server 4182
```

Then open `http://127.0.0.1:4182/index.html`.
