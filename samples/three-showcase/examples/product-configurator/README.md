# Three Product Configurator

A product-stage Three.js sample with a premium lighting setup, procedural earbud model, material finish buttons, soft shadows, and responsive full-screen layout. It imports the vendored module from `../../../shared/`.

## Run

Serve the folder so browser module imports can load correctly:

```bash
python3 -m http.server 4183
```

Then open `http://127.0.0.1:4183/index.html`.
