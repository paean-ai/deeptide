# Three Neon Orbits

A polished Three.js orbital sculpture sample with emissive materials, particle stars, pointer orbit controls, and responsive full-screen layout. It imports the vendored module from `../../../shared/`.

## Run

Serve the folder so browser module imports can load correctly:

```bash
python3 -m http.server 4181
```

Then open `http://127.0.0.1:4181/index.html`.
