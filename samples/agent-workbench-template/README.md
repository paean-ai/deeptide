# Agent Workbench Template

A static HTML template for presenting local coding-agent work. It is designed
for PR descriptions, handoff notes, implementation reviews, and internal
engineering updates.

## Use Cases

- Summarize a coding-agent task after implementation.
- Present the plan, changes, verification, risks, and reviewer focus.
- Turn agent work into a reviewable artifact before merging.
- Create a polished status page for local automation runs.

## Run

Open `index.html` directly in a browser, or serve the repository root:

```bash
python3 -m http.server 4173
```

Then visit:

```text
http://127.0.0.1:4173/samples/agent-workbench-template/index.html
```
