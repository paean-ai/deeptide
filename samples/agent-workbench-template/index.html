Coding-agent delivery template

Make agent work inspectable, reviewable, and easy to merge.

This template gives local coding agents a polished way to summarize intent, implementation, verification, and risks after a task. It is designed for PR descriptions, handoff notes, and internal engineering updates.

Goal

User Request

Persist tool execution metadata so resumed agent sessions can explain what was verified and what still needs attention.

Outcome

Delivered

Added scoped metadata storage, surfaced it in the session summary, and covered the behavior with unit and integration checks.

Plan

Execution Path

  1. Map the current state model Inspected session serialization, resume flow, and summary rendering boundaries.
  2. Add the smallest durable schema Stored command, exit status, duration, and verification label without changing public CLI flags.
  3. Render useful handoff context Grouped checks by outcome and kept noisy command output out of summaries.
  4. Verify the critical path Ran unit tests, resume-flow integration, and a local smoke command.
