# Starforge Idle

Dependency-free HTML Canvas pixel idle/incremental sample.

## Features

- Click and automatic resource production.
- Infinite upgrade levels with exponential costs.
- Machines for idle production, relics for late-game multipliers, and prestige reset.
- LocalStorage autosave and offline earnings.
- Mobile-first controls with large buttons, scrollable shop cards, and safe-area padding.

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 4177
```

Then visit `http://127.0.0.1:4177/index.html`.
