# Pixel Dice

A pixel-art **die-rolling logic puzzle**. A six-sided die tumbles cell by cell
across a grid; every *seal* cell demands one number, and a seal locks when the
die comes to rest on it showing that face up. Lock every seal to clear the
board — then hunt for the shortest tumble path. A fresh roll-and-plan puzzle
genre alongside the other `samples/` pixel games.

## Features

- 6 puzzles on a rising curve — Pip, Tumble, Cascade, Lattice, Gauntlet and
  Cyclone — from a 5×5 board with 3 seals up to a 7×7 board with 6.
- Every puzzle is generated by construction: a random tumble walk lays down a
  guaranteed solution, then a breadth-first search measures par, so each board
  ships solvable with an honest shortest-path target.
- Rolling is real die physics — opposite faces always sum to seven, and a
  roll back the way you came undoes the last one. Plan the orientation, not
  just the route.
- Tap an adjacent cell to roll there; reachable cells are highlighted. Undo
  and restart are always one tap away; arrow keys plus Z / R work on desktop.
- Three-star scoring against par, per-level completion marks and progressive
  unlocks, English/中文 toggle, saved to `localStorage`.
- Verified: 61 checks — roll orientation math (a four-roll loop and a
  there-and-back both return to start, opposite faces stay summing to seven),
  all 6 levels build at or above their par target, every generated puzzle's
  BFS solution path seals every cell in exactly par rolls, undo / restart and
  off-grid guards behave; plus a load check that all four scripts run cleanly.

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4417
```

Then visit `http://127.0.0.1:4417/index.html`.

## Play

- Tap a cell next to the die to tumble it one step in that direction.
- A seal cell shows the number it wants — land on it with that face up and
  the seal locks green.
- Lock every seal to win. Roll off a locked seal and it stays locked.
- Undo walks back one roll; restart returns the die to its start.
- Beat par for three stars.

## Structure

- `index.html` - shell, title / level-select / play screens, result overlay.
- `css/style.css` - responsive 360:480 shell.
- `js/data.js` - die roll math, puzzle generation, BFS par solver, play state.
- `js/i18n.js` - English / Chinese strings.
- `js/art.js` - board, die with pip faces, seal cells, HUD, title art.
- `js/game.js` - screen flow, tap-to-roll input, undo / restart, save.
