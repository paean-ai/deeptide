# Pixel Aquarium

A pixel-art take on the **Aquarium** (hidden-water-level) logic puzzle.
The grid is partitioned into irregular **tanks**; each tank holds water at
a single horizontal level — every cell of the tank at or below the level
is water, every cell strictly above is air. The row and column numbers
count water cells, and you deduce the unique combination of water levels.
A fresh shading-logic puzzle alongside the other `samples/` pixel games.

## Features

- 6-tank-campaign on growing grids (5×5 → 7×7) with 5–8 tanks per board.
- Every puzzle is procedurally generated by:
  1. Round-robin BFS-expansion partition from `k` random seed cells
     (reject if any tank has fewer than 2 cells).
  2. Pick a uniformly-random water level per tank from its `[y_min, y_max+1]`
     range (the upper bound is the "tank empty" state).
  3. Derive row + column counts; verify uniqueness by a tank-by-tank
     backtracking solver that tries each candidate level and prunes by the
     row / column count caps.
- Live red conflict highlight:
  * Row / column over-fill — too many water cells in a row or column.
  * Gravity violation — a water cell with an air cell strictly below it in
    the **same** tank (water should fill bottom-up).
- Tap any cell to cycle **blank → water → air → blank**.
- Score = `999 - seconds` on a clean solve.
- English / 中文 toggle, `localStorage` save with cleared puzzles and best
  scores.
- 360×480 responsive frame, `image-rendering: pixelated`, mobile-first.
- Verified: 44 data checks — every level builds with the right tank count,
  every clue set has exactly one solution, the generator is bit-for-bit
  deterministic, the real solution wins `isSolved`, plus row-overcount and
  gravity-violation conflict cases for `findViolations`.

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4304
```

Then visit `http://127.0.0.1:4304/index.html`.

## Play

- Tap a cell to cycle through **blank → water → air → blank**.
- Numbers around the board count the water cells in each row / column.
- Inside a single tank water must fill bottom-up — you'll never see air
  below a water cell of the same tank.
- Win when every cell is decided and every constraint is satisfied.

## Structure

- `index.html` — shell + script tags.
- `css/style.css` — 360:480 responsive frame, `image-rendering: pixelated`.
- `js/data.js` — partition generator, water-level math, uniqueness solver,
  live violation + win helpers.
- `js/i18n.js` — English / Chinese strings.
- `js/art.js` — palette, glass-tank cell tints, water (with crest line +
  bubble) / air sprites, thick tank borders, HUD.
- `js/game.js` — screen flow, tap input, timer, save.
