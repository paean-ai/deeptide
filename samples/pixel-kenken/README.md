# Pixel KenKen

A pixel-art take on **KenKen** (a.k.a. **Calcudoku**) — a Latin-square
puzzle where each outlined "cage" must satisfy a target value under a
given arithmetic operator (`+`, `×`, `-`, `÷`). Distinct from Sudoku
(uses cages with arithmetic instead of 3×3 blocks) and from Futoshiki
(arithmetic on a region vs `>` / `<` between cells).

## Features

- 6-grid campaign 4×4 → 6×6 (**Foothills → Summit**), with cages of
  1–4 cells: single cells reveal their value with `=`, 2-cell cages
  use any of `+ × - ÷`, 3+-cell cages use `+` or `×` only.
- Every puzzle is generated by picking a random Latin square, BFS-
  partitioning the grid into random cages, assigning an op/target per
  cage from the solution values, and **verified** to have exactly one
  solution by a backtracking solver. Partitions with too many size-1
  cages are rejected (boring puzzles).
- Solver prunes by partial cage sum/product overflowing the target
  (kills branches early on `+` and `×` cages), then exact-match on
  cage completion.
- Live red conflict highlight: row / column duplicates and any
  fully-filled cage that fails its op + target.
- Zero cell hints — the cage labels do everything.
- Selected-cell peer highlight (same row + same column dim up).
- Tap a cell, then tap a digit (1..n) on the bottom pad. **ERASE**
  clears. Keyboard fallback: digits **1..9**, **Backspace**.
- Score = `999 - seconds` on a clean solve.
- English / 中文, `localStorage` save with cleared puzzles + best scores.
- 360×480 responsive frame, `image-rendering: pixelated`, mobile-first.
- Verified: 197 data checks — every level builds, every cage covers
  each cell once, every solution wins `isSolved`, every clue set has
  exactly one solution, generator output is bit-for-bit deterministic;
  plus a row-duplicate conflict case.

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4312
```

Then visit `http://127.0.0.1:4312/index.html`.

## Play

- Tap a cell, then tap a digit on the bottom pad.
- Each row and column must contain every digit 1..n exactly once.
- Every outlined cage must satisfy its label — `5+` means sum to 5,
  `12×` means product 12, `2-` means abs-difference 2, `3÷` means
  larger ÷ smaller = 3, and a bare number means that single cell IS
  that value.
- Repeats are allowed *inside* a cage as long as the Latin-square rule
  isn't broken.

## Structure

- `index.html` — shell + script tags.
- `css/style.css` — 360:480 responsive frame, `image-rendering: pixelated`.
- `js/data.js` — random Latin square, BFS-cage partition, cage op/target
  pick from solution, backtracking uniqueness solver with partial
  +/× prune, live violation + win helpers.
- `js/i18n.js` — English / Chinese strings.
- `js/art.js` — palette, gridded cells with thick cage borders, cage
  labels in the top-left cell of each cage, peer-row/col highlight,
  number pad, HUD.
- `js/game.js` — screen flow, tap input + keyboard fallback, timer,
  save.
