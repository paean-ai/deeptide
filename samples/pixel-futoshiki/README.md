# Pixel Futoshiki

A pixel-art take on **Futoshiki** — a Latin-square puzzle with `>` / `<`
inequality constraints between adjacent cells. Fill every cell with
1..n so each row and column contains every digit, and every inequality
holds. A fresh number-logic puzzle alongside the other `samples/` pixel
games.

## Features

- 9-puzzle campaign on 4×4 → 6×6 grids — **Foothills → Apex**.
- Every puzzle is generated by picking a random Latin square (row-shift
  + row / col / value permutations), reading off **every** adjacent
  `>` / `<` inequality, then greedily REMOVING constraints while a
  backtracking solver confirms the puzzle still has exactly one
  solution.
- **Zero cell hints** — these puzzles are pure-constraint Futoshiki.
  Solved a single Latin square from 5–15 inequalities alone.
- Random Latin squares + ALL inequalities sometimes have multiple
  solutions (a sign-equivalent square slips through on small grids);
  those attempts are rejected and the generator retries with a fresh
  Latin square — handled by the first uniqueness check before trim.
- Live red conflict highlight:
  * Duplicate digit in a row or column.
  * A `>` / `<` sign whose two cells already break the inequality.
- Tap a cell to select; tap a digit (1..n) on the bottom pad to fill;
  **ERASE** clears the cell. Keyboard: digits **1..9**, **Backspace**.
- Selected-cell **peer highlight** (same row + same column dim up).
- Score = `999 - seconds` on a clean solve.
- English / 中文, `localStorage` save with cleared puzzles + best scores.
- 360×480 responsive frame, `image-rendering: pixelated`, mobile-first.
- Verified: 39 data checks — every level builds with the right `n`,
  every solution is a valid Latin square, every clue set has exactly
  one solution, generator output is bit-for-bit deterministic; plus
  row-duplicate and broken-inequality conflict cases.

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4308
```

Then visit `http://127.0.0.1:4308/index.html`.

## Play

- Tap a cell to select it, then tap a digit (1..n) on the bottom pad.
- Each row and each column must contain every digit 1..n exactly once.
- The `>` and `<` signs between cells point at the *smaller* value.
- Win when every cell is filled and no rules are broken.

## Structure

- `index.html` — shell + script tags.
- `css/style.css` — 360:480 responsive frame, `image-rendering: pixelated`.
- `js/data.js` — random Latin square generator, constraint enumeration,
  backtracking uniqueness solver, greedy constraint trim, live violation
  + win helpers.
- `js/i18n.js` — English / Chinese strings.
- `js/art.js` — palette, gridded cells with `>` / `<` signs in the
  gaps, peer/row/col highlight, number pad, HUD.
- `js/game.js` — screen flow, tap input, keyboard fallback, timer,
  save.
